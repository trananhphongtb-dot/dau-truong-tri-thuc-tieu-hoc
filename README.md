# Đấu Trí Tiểu Học

Game hỏi đáp kiến thức cho học sinh tiểu học, chủ yếu lớp 4-5, 3 phần thi: **Khởi động – Đấu Trí – Về Đích**.

- 5.000 câu hỏi, 7 môn: Toán, Tiếng Việt, Tiếng Anh, Khoa học, Lịch sử - Địa lí, Tin học, Đạo đức
- Độ khó theo cách xử lý: 1 = nhận biết, 2 = hiểu / vận dụng đơn giản, 3 = suy luận / vận dụng
- Đăng nhập Google, thi trực tuyến 2–4 người, phòng chờ, kết bạn, xếp hạng
- Package: `vn.dautruongtrithuc.tieuhoc`
- Firebase: `dau-truong-tri-thuc-tieu-hoc` (tách riêng, không chung với app Đấu Trường Trí Thức cũ)

## Lấy file APK
Mỗi lần đẩy code lên nhánh `main`, GitHub Actions tự build.
Vào tab **Actions** → chọn lần chạy mới nhất → mục **Artifacts** → tải `DauTriTieuHoc-debug`, giải nén ra file `.apk` để cài.
